# /review-neta — 週次棚卸し

ネタの週次棚卸しを実行してください。

## 手順

1. **整合チェック**: `neta/**/*.md`（TEMPLATE.md を除く）の frontmatter と `neta/INDEX.md` の表を突き合わせ、
   ステータス・カテゴリ・チャネル・リンクのズレがあれば INDEX.md 側を修正する。
2. **サマリ報告**: ステータス別の件数（アイデア / 進行中 / 公開済み / 見送り）と、直近1週間の動きを報告する。
3. **停滞の指摘**: 進行中 (doing) のうち「メモ・進捗ログ」が2週間以上更新されていないネタを指摘し、
   継続するか見送り (dropped) にするかユーザーに確認する。
4. **今週のネタ提案**: アイデア (idea) の中から今週着手する候補を2〜3件提案する。
   ユーザーが選んだら該当ファイルを `status: doing` に更新し、INDEX.md の「🔧 進行中」に移す。
5. **公開済みの確認**: published のネタに `published` 日付と `links` が入っているか確認し、
   欠けていればユーザーに聞いて埋める。

## 注意

- ネタ本文・投稿ドラフトの内容は書き換えない（ステータス・日付・リンクの更新のみ）。
- 見送りにする判断はユーザー確認なしに行わない。
